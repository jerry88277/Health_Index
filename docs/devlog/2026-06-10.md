### 規劃

### 測試／驗證
| 項目 | 結果 |
|---|---|

| 全套件 | 200 passed / 2 skipped |

### Wisdom 雷區
- **誠實性禁得起紅隊反駁才算數**：紅隊 A 實測「換 held-out baseline 仍無法分離 TEP drift（3/8 seed）」
  → 證「TEP drift 非 Y-訊號、是 X-關係問題（L2 抓）」是誠實結論，非掩蓋可修指標。不假裝 Y 健康強烈
  旗標 TEP drift（那是造假）。
- **融合均值會遮蔽單分量崩**：B/C dist→0 但 map≈1 → 均值~0.5「中等」漏掉換產品 → 加 y_flagged 安全網
  （任一分量<門檻），保留均值梯度（對稱 X 側）+ 旗標決策（紅隊 A1）。
- **「對稱」勿過度宣稱**：YHealthIndex 無 FWER/threshold 決策層（X 側有）→ 措辭軟化為「部分對稱」（紅隊 B2）。
- **測試斷言量級會 cherry-pick seed**：marquee 改斷言**方向**（跨 seed 穩健）而非特定 seed 量級（紅隊 A3）。
- **CP↔2std 帶寬不連續**：golden 標籤跨 cp_min_calibration 門檻時帶寬跳 ~39% → map 跳變；誠實標（紅隊 A2）。
- **端點 row 語意要與兄弟端點 parity**：/yhealth_index 改 STEADY 過濾，與 /analyze 同（排除 settling 段，紅隊 B1）。

## 11:49:33 +0800 — 桶2a PLS 可擴展軟測量 + 規模選擇器（merge 93efb0f）[verified]

### 規劃
桶1 解鎖後續推桶2（X&Y 軟量測核心）。第一性原理：軟測量 Ŷ=f(X)；GPR O(n³)、RBF 高維退化 → 不適
「多製程參數 + 大資料集」泛化。PLS 為製程業經典軟測量（投影潛在成分、共線穩健、O(n·p·k)）。

### 開發（commit cf9b39d + 紅隊修正 a78e4fa）
- `soft_sensor.py`：`PLSSoftSensor`（PLS + split-CP，同 SoftSensor 介面）；`_split_conformal_q`（抽出
  model-agnostic CP 分位，GPR/PLS 共用）；`make_soft_sensor`（依規模選基底：p>30 或 n>1000 → PLS）。
- `config.py`：pls_components + 選擇器門檻。
- `server.py`：/softsensor 改用 make_soft_sensor；band_kind 反映基底（GPR_std/PLS_std）；
  **新增 server 資料集 synthetic_hd（p=40 + 密集 Y）→ PLS 路徑端到端可達**（紅隊 B-D1）。
- `frontend`：dropdown 加「高維合成」。

### 測試／驗證
| 項目 | 結果 |
|---|---|
| PLS 128 維共線 held-out R² | 0.999（5 成分；GPR/RBF 在此退化） |
| PLS split-CP 覆蓋（disjoint） | 0.90±0.03，含 p>n、純噪 X⊥y 仍守保證（紅隊實測 model-agnostic） |
| 選擇器 | p=10/22→GPR（向後相容）、p=128/n>1000→PLS；off-by-one 正確 |
| synthetic_hd 端到端 | /softsensor cp_available=True、/analyze p=40 全鏈跑通、reentry [2,4] |
| 向後相容 | synthetic/tep /softsensor 仍 GPR、yhat 逐位元一致 |
| 紅隊複審 | ≥2 視角；A SHIP、B FIX-FIRST（可達性）→ 修正後全綠 |
| 全套件 | 189 passed / 2 skipped |

### Wisdom 雷區
- **不要交付「死 scaffolding」**：PLS 原本只在單測跑，無 server 路徑觸發（uci 無 Y 且未接線）→ 紅隊
  B-D1 抓到。改加高維 server 資料集 synthetic_hd 使其端到端可達，才算真交付（誠實＞鋪墊）。
- **split-CP 是 model-agnostic**：以 PLS 為基底仍守有限樣本覆蓋（紅隊實測純噪/p>n 皆 0.90）——前提是
  **disjoint calib**。server 因 golden 標籤少改 in-sample 校準 → 覆蓋為近似（紅隊 A-D1，已誠實標）。
- **全常數 X 會讓 PLS deflation NaN crash**（GPR 不會）→ fit 邊界 fail loud（紅隊 A-D2）。
- **PLS 同方差殘差 std**：無後驗變異，無 CP 時的 band 為常數（異質噪聲下逐區校準不準）——誠實標。
- **多輸出宣稱要對齊實作**：PLS 演算法支援多 Y，但本版純量；docstring 改「演算法支援、本版純量」（B-D2）。

### Wisdom 雷區
- **抽象門檻已達才抽**：3 個 bespoke `*GroundTruth` + 入口名 generate/load 不一 → 第 3 次重複，
  統一協定justified（Rule 2 不為單次預抽象）；用 Callable 別名而非 runtime_checkable Protocol（對自由
  函式 isinstance 無實益）。
- **轉換器不可型別嗅探**：原 `isinstance(b[2], str)` 猜 bounds 形狀，整數 grade 會誤判 → 改由呼叫端
  **明示** `_campaign_segments`/`_batch_segments`（紅隊 A#3）。
- **numpy 欄 + frozen dataclass 自動 __eq__/__hash__ 是陷阱**：比較拋 ambiguous-truth、雜湊 unhashable
  → `eq=False`（此型別供消費非比較，紅隊 A#4）。
- **通用攝入要在邊界 fail-loud**：非數值 X 不可延後到 fit 才拋晦澀錯 → from_frame 即擋（紅隊 B#1）；
  預設 golden 啟發式（前 30%）須發 RuntimeWarning，不靜默（紅隊 B#3）。
- **tep_tp 防呆**：`setdefault` 讓 `time_preserving=False` 靜默得到 iid 情境（名實不符）→ 明示 False 即
  fail loud（紅隊 A#1）。
- **worktree 隔離會讓紅隊誤判「phantom doc」**：roadmap 已 commit 於 main 但未推送 → worktree（branch
  自 origin/main）看不到。屬流程 artifact，非真缺；合併後即在。
