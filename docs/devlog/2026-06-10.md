## 13:13:10 +0800 — 桶4 from_frame 缺值處理（merge 2823b19）[verified]

### 規劃
第一性原理：真實連續製程資料**必有**感測器斷點（NaN）。from_frame（桶1 通用攝入）原靜默放行 → NaN

### 開發（commit 525d24d + 紅隊修正 682cbf7）
- `dataframe.py`：X 有 NaN 且未指定 impute → **邊界 ContractError**（不靜默補）；impute='median'/'ffill'
  opt-in 填補 + 警告。`_impute_x` helper。Y/yq_ 的 NaN（稀疏量測語義）不動。
- 紅隊修正：inf 同 NaN 邊界擋（A3）、缺欄清楚 ContractError 非 KeyError（A4）、警告排序（A5）。

### 測試／驗證
| 項目 | 結果 |
|---|---|
| NaN 預設 fail-loud | ContractError at boundary（不延後到 fit） |
| median/ffill 填補 | 全鏈跑通 HI>0.8；稀疏 Y 保留 |
| inf/缺欄/全 NaN/未知策略 | 皆邊界 fail-loud |
| 向後相容 | NaN-free 值等價（int→float 升格，contract 不在意，紅隊查證良性） |
| 紅隊複審 | ≥2 視角；**A 實證填補會遮蔽飄移（+0.20 假陰性）** → 強化誠實警告 |
| 全套件 | 215 passed / 2 skipped |

### Wisdom 雷區
- **填補會製造假陰性，不只是「扭曲」**：median 把缺值塞到邊際中心＝golden 認為合規處 → **系統性
  拉高飄移段健康度、遮蔽飄移**（紅隊實測 +0.20）。這是任何填補的**本質風險**、非可調；警告改強標
  （Rule 12）。golden-only median 也救不了（fundamental）→ 誠實標而非換指標。
- **isna() ≠ 非有限**：inf 不被 NaN 閘擋，會延後崩——與「邊界 fail-loud」精神不一致 → 補 isinf 閘（A3）。
- **fail-loud 要在「邊界」且「先於警告」**：缺欄給清楚 ContractError 非 raw KeyError（A4）；X 驗證錯誤
  須先於 golden 啟發式警告 raise，不漏警告（A5）。
- **重構勿默默改 dtype**：astype(float) 把 int/bool X 升 float；幸好 contract/下游不依賴 X dtype（紅隊查證）。

### Wisdom 雷區
- **抽象門檻已達才抽**：3 個 bespoke `*GroundTruth` + 入口名 generate/load 不一 → 第 3 次重複，
  統一協定justified（Rule 2 不為單次預抽象）；用 Callable 別名而非 runtime_checkable Protocol（對自由
  函式 isinstance 無實益）。
- **轉換器不可型別嗅探**：原 `isinstance(b[2], str)` 猜 bounds 形狀，整數 grade 會誤判 → 改由呼叫端
  **明示** `_campaign_segments`/`_batch_segments`（紅隊 A#3）。
- **numpy 欄 + frozen dataclass 自動 __eq__/__hash__ 是陷阱**：比較拋 ambiguous-truth、雜湊 unhashable
  → `eq=False`（此型別供消費非比較，紅隊 A#4）。
- **通用攝入要在邊界 fail-loud**：非數值 X 不可延後到 fit 才拋晦澀錯 → from_frame 即擋（紅隊 B#1）；
  預設 golden 啟發式（前 30%）須發 RuntimeWarning，不靜默（紅隊 B#3）。
- **tep_tp 防呆**：`setdefault` 讓 `time_preserving=False` 靜默得到 iid 情境（名實不符）→ 明示 False 即
  fail loud（紅隊 A#1）。
- **worktree 隔離會讓紅隊誤判「phantom doc」**：roadmap 已 commit 於 main 但未推送 → worktree（branch
  自 origin/main）看不到。屬流程 artifact，非真缺；合併後即在。
